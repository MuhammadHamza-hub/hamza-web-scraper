# Web Scraper - CodeAlpha Internship Task 1

This repository contains the source code for Task 1 of the CodeAlpha Internship. It is a Python-based web scraping tool that extracts specific web content, parses structured data, and outputs it into an accessible format.

## Features

- Scrapes targeted elements from specified URLs.
- Extracts and cleans raw web page data.
- Handles standard HTTP requests and processes HTML content using Python libraries.
